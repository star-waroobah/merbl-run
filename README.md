## About
Merbl run, my Half Life Week 2 project. A 3D-printed marble run designed in Onshape using the Hack Club guide.

## What's in it
- A snake-shaped track with three curves
- A staircase track section
- A funnel that catches the marble
- An 8 mm marble, and a flat base for printing
